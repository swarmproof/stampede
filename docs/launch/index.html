The blind spot

Load tests measure throughput.
Agents generate behavior.

A load test fires uniform, well-formed traffic and varies only the rate. It holds fixed the one thing agents refuse to hold fixed: the decision of what to call, and why.

What a load test sees

Is it strong?

  • requests per second, sustained
  • p99 latency under load
  • error rate, memory, connections
  • every request is the one you designed

What the wind tunnel sees

How does it behave?

  • which tool an agent picks — and mis-picks
  • retry loops that amplify one fault into a storm
  • confusion under concurrency and temperament
  • the misuse map, not the success rate

Misuse map

Where agents called the wrong tool for their goal — the two most-used tools are mutually confusable, and one of them moves money.
